# Humanoid animation rule

Julian's standing instruction (2026-10-30): use the pose guides for **all future humanoid characters**, including Thomas, enemies and NPCs.

- Read `design/art-briefs/animation/guides/README.md` and the animation brief before drawing. Use the supplied guides as the source of each pose.
- Paint one frame at a time. Preserve anatomical limb identity: left leg red, right leg blue, left arm orange, right arm cyan in the guides. Remove these diagnostic colours from finished art.
- Match the guide's feet, knees, weight transfer, limb overlap and camera. Compare each painted frame against its guide, then inspect the assembled loop for alternating leading legs, arm opposition and foot sliding.
- Add costume and secondary motion without hiding the leg movement. Follow each character's approved proportions and job specifications; Thomas's measurements are not universal enemy dimensions.
- If a character's proportions, action or direction need a different guide, record the missing guide in the pull request for Claude to supply. Do not invent an unsupported animation cycle or mark it delivered.

The parent `AGENTS.md`, house style and asset ownership rules still apply. Existing approved art is not automatically replaced by this instruction.
