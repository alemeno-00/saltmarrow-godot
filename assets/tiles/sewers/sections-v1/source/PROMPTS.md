# Room-section generation prompts

Tool: built-in image generator. Original Sewer Tileset v0.2 and corridor-v2 benchmark supplied as style references. All three room paintings are newly generated; no original artwork is claimed as a converted atlas. The generator did not follow the requested pixel dimensions or connection profile exactly. The reproducible export script registers source landmarks to a shared native profile and records that operation in the manifest.
