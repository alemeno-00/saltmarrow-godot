# Binding visual acceptance — sewer fidelity revision

The user requires the actual Godot assembly to match the approved Sewer Tileset v0.2 concept and camera standard. The corridor-v2 image is a supporting visual benchmark, not a substitute production atlas.

Required: slightly angled top-down on an orthogonal square grid; deep small-brick faces beneath substantial chipped capstones; recessed thick arches; consistent proportions and pixel-cluster detail; wet brown/charcoal/slate materials; sparse moss, salt and tide marks; dark restrained water; corroded fantasy fittings; small localized amber lighting. The 32px ground grid does not constrain larger masonry canvases to one tile.

Reject flat blocks, repeated identical stamps, visibly framed floor tiles, decorative neon water borders, random noise, smooth painted sprites, arbitrary rotations, uniformly lit orange rooms, and falsely claimed production conversion. Technical tests are independent and cannot establish visual acceptance. New generated source, production exports and original concept imagery must be distinguished.

This folder is a revision candidate. Do not call it approved or concept-identical without user visual approval of an actual Godot render. Preserve earlier prototypes for comparison. Source files are not shipping atlases. Actor placeholders, incomplete corners, UI and lighting limitations must be stated in the review.
