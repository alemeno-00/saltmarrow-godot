# Saltmarrow art documentation

- [Saltmarrow Deep biome and layout guide](saltmarrow-deep-biome-layout-guide.md): central art-design contracts, six biome grammars, 30 archetypes per biome, the supplied sewer reference library, transitions and production acceptance criteria.

- [Approved camera-perspective concept reference](references/README.md): supplied illustration, provenance, scale interpretation and production limitations.

The central guide includes the approved slightly angled top-down dungeon visual standard: 32 × 32px base tiles, consistent scale, biome materials, restrained lighting, readable hazards and modular sprite requirements.

This folder contains design documents and a concept illustration, not production sprites. Image/frame size, animation rows, frame counts and facing directions are not applicable. Follow the repository's AGENTS.md and ART_JOBS.md for actual art exports. This guide does not complete any queued sprite job.
