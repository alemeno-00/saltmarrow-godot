# Saltmarrow art documentation

- [Saltmarrow Deep biome and layout guide](saltmarrow-deep-biome-layout-guide.md): central art-design contracts, six biome grammars, 30 archetypes per biome, the supplied sewer reference library, transitions and production acceptance criteria.

This folder contains Markdown design documents, not production sprites. Image/frame size, animation rows, frame counts and facing directions are not applicable. Follow the repository's AGENTS.md and ART_JOBS.md for actual art exports. This guide does not complete any queued sprite job.
