# Concept review — actual results, not prompt promises

## Canonical reference v1

Useful: same recognisable face across the sheet, lean ordinary build, plain dark coat, scarf, canvas satchel and small lantern; front, right-three-quarter and back full-body views are all present. Empty hands and no armour or magic.

Needs revision before approval: large portrait faces LEFT; hair is too long/tousled for the army-short written baseline; coat is very ragged and can become simpler repaired clothing. Scar anatomical placement needs reconciliation across views: the large left-facing portrait exposes the opposite side from the specified right-facing portrait. Ear notch is not reliably defined. Satchel/lantern orientation and attachment need checking across front/back. Treat the sheet as reference proposals, not a locked turnaround.

## First class-reference pass — rejected, not included as deliverables

Separate prompts for Fury, Shadow, Elementalist, Censor and Talent used the canonical sheet as reference. The model preserved the greatcoat too strongly: Shadow mostly added a hood, Elementalist mostly added a staff, Censor mostly added a small censer, and Talent barely changed. These attempts did not meet the five-distinct-costumes requirement. They are not counted as completed variants or shipped as source files. Their prompts are retained for provenance. The selected v2 lineup is a fresh costume pass using the portrait master for face identity only.
